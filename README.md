## 🚀 Quick Start

### Prerequisites
-   Node.js (v18+)
-   npm or bun

### Installation

1.  **Clone the repository**
    ```bash
    git clone <repo-url>
    cd uzb-beauty-find-main
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start development server**
    ```bash
    npm run dev
    ```
    The app will run at `http://localhost:8080` (or similar).

## 🛠 Tech Stack
-   **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, shadcn/ui
-   **Backend**: Supabase (Auth, Database, Storage)
-   **Maps**: Leaflet

## 🔑 Key Features
-   **Smart Booking**: Real-time slot selection.
-   **Gamification**: Earn coins, enter lotteries.
-   **Business Dashboard**: Manage your salon and clients.
-   **Trusted Reviews**: Verified feedback system.
